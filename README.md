# Jarvis

Jarvis는 개인이 자기 맥북에서만 쓰는 음성 비서입니다. 일반에 배포하거나 판매하지 않습니다.

Jarvis is a personal voice assistant that runs only on its developer's own Mac. It is not distributed or sold.

## 구글 캘린더 사용 / Google Calendar use

- 요청 범위: `https://www.googleapis.com/auth/calendar.events.owned`
- 사용자가 말로 요청할 때 일정을 조회하고, 사용자가 화면이나 말로 승인한 경우에만 일정을 등록·수정·삭제합니다.
- Reads events on request, and creates, updates or deletes events only after the user explicitly approves each change.
